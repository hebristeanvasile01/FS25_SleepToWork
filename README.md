# Sleep To Work – FS25

Even a farmer needs sleep! After **14 hours of work** you are too tired to drive and you have to sleep before you can work again.

![icon](icon_preview.png)

## Features
- Every in-game hour you drive a vehicle with the motor running counts as work.
- At 14 hours you are exhausted: one message on screen, the motor stops and will not start again.
- Press **R** to sleep: the game's own sleep (your farmhouse bed) starts and time fast-forwards.
- 6+ hours of sleep = fully rested. A short nap gives back 2 hours of work per hour slept.
- Hired helpers are not affected.
- Work time is shown on screen while you drive and is saved with your savegame.

## Console
| Command | What it does |
|---|---|
| `stwStatus` | Show your work time |
| `stwSet 13.5` | Set the work time (for testing) |
| `stwLimit 14` | Change the work limit |

## Install
Download the latest release ZIP (or the repository as ZIP, with the files at the root of the zip), name it `FS25_SleepToWork.zip` and put it in your `mods` folder.
